# Yash Chauhan

I build full-stack AI systems where the important question is not only whether the model can answer, but whether the answer can be trusted, inspected, and operated.

Currently focused on [GlassBox](https://github.com/yash-vks-chauhan/Glassbox), an auditable wealth-advisory AI agent that answers from cited sources, refuses unsupported questions, records decision trails, and exposes trust metrics through a governance dashboard.

## What I Build

- AI applications with retrieval, verification, evaluation, and safe fallback paths.
- Operational dashboards that make system state, risk, and model behavior visible.
- ML pipelines where metrics, failure modes, and auditability matter.
- Full-stack products with practical backend, frontend, database, and deployment concerns.
